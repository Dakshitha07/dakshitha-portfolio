Dakshitha Pathipati: portfolio website

HOW TO VIEW
Open index.html in a browser. It needs an internet connection (React, Tailwind and fonts load from CDNs).

HOW TO PUBLISH
Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages) with index.html at the top level.

HOW TO UPDATE
- Work designs: put images in images/work/ and add an entry to the PROJECTS list near the top of the script in index.html.
- Portrait: replace images/portrait.jpg.
- PDFs: pages are images in images/documents/<name>/. Add a new folder and an entry to DOCS.
- Email, phone, LinkedIn, Instagram: edit the SITE block in index.html.
- Experience, tools and services: edit the EXPERIENCE, TOOLS and SERVICES lists.
